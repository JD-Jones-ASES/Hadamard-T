# Cert 01 — the public H(2060), pinned and decoded

## Statement

The artifact `data/H2060.txt.gz` is a Hadamard matrix of order 2060. It is not
opaque. It is the ×104-twisted Goethals–Seidel array over a four-sequence seed
on `Z₅₁₅`, and that seed is generated by a **single T-matrix quadruple of
order 103**.

1. **The artifact.** Payload SHA-256
   `c7a145d86210740dd3f8ea21ca896a54d6916007a042638f17c8c47f097200f7`, 2060
   lines of 2060 characters over `{+,-}`, accepted by `verify/verify.py`.
   Provenance is in [`data/PROVENANCE.md`](../../data/PROVENANCE.md). The
   matrix is Schneider's; this laboratory decoded it and did not find it.
2. **The seed.** Four `±1` sequences of length 515 with row sums
   `(−17, 5, 39, 15)`, `Σ rᵢ² = 2060 = 4v`, and `Σ_q PAF_q = 2060·δ₀`.
3. **The tier.** Translated by `(0, 206, 206, 206)` the seed is strictly
   invariant under the order-6 multiplier group
   `⟨149⟩ = {1, 46, 56, 104, 149, 159} ≤ U(Z₅₁₅)`. Untranslated it reads only
   `⟨46⟩`, order 3.
4. **One seed, two arrays.** The plain Goethals–Seidel array over the seed is
   a second, different H(2060), canonical SHA-256
   `510f89b7b423c85da0c7cada52cb0f62e0415d736d2040d6701f66c4e524cf6a`. The
   ×104-twisted array, relabelled through `ORD[g] = 5(g mod 103) + (g mod 5)`,
   reproduces the artifact byte for byte (4 245 660 bytes).
5. **The generator.** Under the CRT split `Z₅₁₅ ≅ Z₅ × Z₁₀₃` the seed's twenty
   fibres collapse to ten distinct length-103 sequences, eight up to global
   sign, and all ten are sign combinations `Σᵢ εᵢ Tᵢ` of one ternary quadruple
   `T` with disjoint supports of sizes `(33, 30, 19, 21)` partitioning `Z₁₀₃`
   and `Σᵢ PAF(Tᵢ) = 103·δ₀`.
6. **The assembly is order-agnostic.** The 20 × 20 template that consumes the
   quadruple is re-run on an independently brute-forced quadruple of length 3
   and returns a `verify.py`-green H(60): `T(t) ⟹ H(20t)`.

**The order-103 object satisfies the periodic identity only.** It is a
**T-matrix quadruple**, which is exactly the Cooper–Wallis hypothesis. Its
aggregate non-periodic autocorrelation is nonzero at 94 of the 102 positive
lags, so it is **not** an aperiodic T-sequence. Aperiodic `TS(103)` is open
and is not claimed here, or anywhere in this repository.

## How to run

```
python verify/verify.py --selftest        # the trust chain
python certs/01-h2060-artifact/run.py     # ~9 s, exit 0
python certs/01-h2060-artifact/run.py --quick    # skips the order-2060 work
```

Standard library only, from the repository root. `numpy` is used, if present,
for one cross-check outside the trust chain in `[A]`, and is never required.
Three matrices are written to scratch files and deleted; nothing is committed.

## Scope

This certificate binds the structure of the artifact and nothing more. It is
not a find of H(2060): that order was closed by the public record on
2026-08-23. It says nothing about other Hadamard matrices of order 2060, and
nothing about the status of order-103 T-objects beyond the label above.
